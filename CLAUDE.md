# Dragline — каталог б/у спецтехники из Кореи

## Что это
Сайт-каталог б/у экскаваторов, запчастей и спецтехники из Южной Кореи.
Покупатели — Узбекистан/Кыргызстан/СНГ + English-аудитория.
Сделка: я выкупаю технику у корейца через своё ИП/법인 и отправляю покупателю.
Сайт = витрина, НЕ маркетплейс с оплатой. Все объявления добавляются вручную
через Telegram-бота (админку) — формы добавления на сайте нет и не будет.

---

## Стек — что используется сейчас

### Фронтенд (сайт)
- **HTML + CSS + Vanilla JS.** Без React/Vue/фреймворков, без сборщиков.
- **Хостинг:** GitHub Pages (репо `StrongMuslim/dragline`, ветка `main`).
- **Данные читаются напрямую из Google Sheets через gviz API** (бесплатно,
  без лимитов): `https://docs.google.com/spreadsheets/d/SHEET_ID/gviz/tq?tqx=out:json&sheet=Sheet1`.
  SheetDB **не используется** — это сделано специально, чтобы не тратить
  общий с Unity Beauty лимит токенов SheetDB.
- **Фото** хранятся в Cloudinary, в таблице — только готовые URL (через запятую
  для нескольких фото на объявление).
- **Курс валют** KRW→USD: бесплатный API `open.er-api.com`, кэш в localStorage
  на 1 час, fallback — захардкоженная константа в `currency.js`.
- **4 языка:** kr / uz / ru / en. JSON-файлы в `/locales`. Модалка выбора
  языка при первом визите, дальше — переключатель в шапке. Выбор хранится
  в `localStorage`, дефолт — по языку браузера, fallback — `en`. Локали
  грузятся с `cache:'no-store'`, чтобы обновления переводов сразу были видны
  у постоянных посетителей.

### Каталог (index.html)
- Текстовый поиск по марке/модели/названию (живой фильтр).
- Сортировка: сначала новые (по умолчанию) / цена ↑↓ / год ↑↓.
- Переключатель "скрыть проданные".
- Пагинация "показать ещё" — рендерит по 12 карточек за раз.
- Бейдж "NEW" на последних 3 добавленных в таблицу объявлениях (по порядку
  строк в Google Sheet — бот дописывает новые в конец).
- Экран загрузки (спиннер) + экран ошибки с кнопкой "Повторить", если gviz
  недоступен.

### Страница лота (listing.html)
- Кнопка "Поделиться" — Web Share API на мобильных, копирование ссылки
  в буфер (с тост-уведомлением) на десктопе.
- Галерея с лайтбоксом — клик по фото открывает полноэкранный просмотр,
  навигация стрелками/клавиатурой (←/→/Esc), закрытие по клику на фон.
- Блок "Похожие объявления" — до 4 карточек той же категории/марки
  (available только), скрывается если похожих нет.
- Тот же экран загрузки/ошибки, что и в каталоге.
- Статичные OG-теги (og:title/description/type/site_name) — **без og:image**,
  т.к. сайт полностью клиентский (нет SSR/prerender), а без готовой картинки
  генерировать og:image неоткуда. Превью в Telegram/WhatsApp будет
  текстовым (заголовок+описание), без картинки.

### Бот-админка (Telegram)
- **Python** (`python-telegram-bot==21.3`), деплой на **Render** (free tier).
- Доступ только у одного админа: команда `/admin` + секретный код
  (`ADMIN_SECRET` в переменных окружения Render).
- Бот пишет прямо в Google Sheets через **gspread** (Google Service Account,
  JSON-креды в env-переменной `GOOGLE_CREDS_JSON`) — тоже без SheetDB.
- Бот **сам загружает фото в Cloudinary** (папка `dragline`, отдельная от
  Unity Beauty) и сохраняет готовые URL в таблицу — руками ничего заливать
  не нужно.
- Функции бота (все через `/admin` → меню):
  - **Добавить объявление** — пошаговый диалог (категория → марка → модель →
    год → моточасы → состояние → цена → локация → совместимые модели → фото →
    названия и описания на 4 языках). Есть кнопка "Такое же" (копирует RU-текст
    в остальные языки) и "Пропустить".
  - **Редактировать** объявление — выбор поля → новое значение.
  - **Удалить** объявление.
  - **Изменить статус** — available / reserved / sold.
  - **Список** объявлений с ID.
- `/health`-эндпоинт (aiohttp) для UptimeRobot — пингуется каждые 5 минут,
  чтобы Render free tier не засыпал через 15 минут простоя.
- Зафиксирован Python 3.11.9 через `.python-version` (python-telegram-bot
  несовместим с 3.14, которую Render ставит по умолчанию).

### Секреты
- Токен бота, ADMIN_SECRET, GOOGLE_CREDS_JSON — **только** в переменных
  окружения Render, никогда не коммитятся. В репо — только `.env.example`
  с плейсхолдерами.

## Структура данных (Google Sheet, лист "Sheet1")
Порядок колонок фиксирован (индексы 0–19), должен совпадать между
`bot.py` (`COLUMNS`) и `js/shared.js` (`fetchListings()`):

```
id, category, brand, model, year, hours, condition, compatible_models,
price_krw, location_kr, status, name_kr, name_uz, name_ru, name_en,
desc_kr, desc_uz, desc_ru, desc_en, photos
```
`category`: excavator / parts / other_machinery
`status`: available / sold / reserved

## Структура файлов
```
index.html        — каталог с фильтрами (категория/марка/цена)
listing.html       — страница лота (галерея, цена KRW+USD, контакты)
about.html         — "как это работает"
css/style.css
js/i18n.js          — языковая модалка + переключение + t()
js/currency.js      — курс KRW→USD, кэш, форматирование
js/shared.js        — общее для main.js и listing.js: fetchListings()
                      (чтение gviz), computeNewIds(), buildCardHTML()
                      (сборщик карточки с опциями), showErrorState()
js/main.js          — поиск/сортировка/фильтры/пагинация, рендер каталога
js/listing.js       — рендер лота, галерея-лайтбокс, share, похожие лоты
locales/{kr,uz,ru,en}.json
bot/bot.py          — Telegram-бот-админка
bot/requirements.txt, Procfile, .python-version, runtime.txt
```

Минимализм, индустриальная тема: тёмно-синий + оранжевый/жёлтый акцент.
Inter/Roboto (кириллица+латиница), Noto Sans KR для хангыля.
Полностью responsive, мобильный приоритет.

## Правила работы (важно!)
1. Перед написанием кода — сначала план (какие файлы, что меняется),
   жду одобрения.
2. Точечные правки в одобренных файлах, не переписывать целиком без запроса.
3. Маленькие шаги: один шаг = одна проверяемая фича.
4. После каждого шага — что сделано и как проверить в браузере.
5. Если предлагаешь архитектуру отличную от описанной — кратко объясни
   почему и жди одобрения.
6. Токен бота, ADMIN_SECRET и Google-креды — никогда не в git, только в
   переменных окружения Render.
7. Ничего не добавлять в продовую Google Sheet без явного одобрения.
